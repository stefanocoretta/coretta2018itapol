# Data Package of an Exploratory Study of Italian and Polish Voicing Effects (Coretta 2018)

This is an R data package with data from Stefano Coretta's PhD dissertation, [Study I](https://stefanocoretta.github.io/phd-thesis/s-methods.html#s:studyi).

More information on the data can be found at <https://osf.io/w92me/> and <https://osf.io/8zhku/>.
